# Study Fusion frontend

## Run locally

```powershell
npm install
npm run dev
```

## Deploy to Netlify

The repository-root `netlify.toml` configures Netlify to use this directory as
the base, run `npm run build`, publish `dist`, and serve the React app for
client-side routes. Connect the repository to Netlify and use the detected
configuration; no separate build settings are needed.
